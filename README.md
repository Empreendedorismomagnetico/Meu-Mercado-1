# Meu Mercado

Aplicativo para organizar compras de mercado.

## Funcionalidades

- Cadastro de produtos
- Edição de quantidade e preço
- Cálculo automático do total
- Finalização de compras
- Histórico de compras
- Calendário de compras
- Detalhes e observações das compras

## Tecnologia

- React Native
- Expo
- JavaScript
- AsyncStorage

## Plataforma

Android (APK).
